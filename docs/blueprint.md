# **App Name**: PensionWise

## Core Features:

- Pension Calculator: Calculate estimated pension income based on user input and display potential scenarios.
- Personalized Recommendations: AI powered tool that provides customized pension plan recommendations based on the user's age, income, and risk tolerance.
- Plan Comparison: Allow users to compare different pension plans side-by-side, highlighting key features and benefits.
- Resource Library: Offer a collection of articles, guides, and videos related to retirement planning and pension management.
- Contact Form: Allow users to reach out with questions or requests.

## Style Guidelines:

- Primary color: Deep blue (#34495E) to inspire trust and security, suitable for financial services.
- Background color: Light gray (#F4F6F6), close to white but not stark, offering a gentle contrast against content.
- Accent color: Soft green (#2ECC71), conveying growth and prosperity.
- Font: 'PT Sans', a humanist sans-serif, suitable for headlines and body text.
- Use simple, professional icons to represent different pension plans and investment options.
- Ensure a clean and intuitive layout with clear sections for pension calculation, plan comparison, and educational resources.
- Use subtle animations to enhance user interaction and provide visual feedback.
